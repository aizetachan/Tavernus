# Legado: VM e2-micro de Google con el bot de Discord

Estos scripts desplegaban el **bot de Discord** en una VM gratuita de Google Cloud
(`create-vm.sh`, `setup-vm.sh`, `push.sh`, `tavernus.service`, `on-exit.sh`). Discord ya no se
usa y el producto es la web, que se despliega con los scripts de la carpeta de arriba
([`docs/DESPLIEGUE.md`](../../docs/DESPLIEGUE.md)). Se quedan aquí solo como referencia;
no se mantienen y las rutas que usan (`deploy/setup-vm.sh`…) ya no son las de esta carpeta.
